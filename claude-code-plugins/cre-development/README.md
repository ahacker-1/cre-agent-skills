# CRE Development and Construction Claude Code Plugin

Install this folder into your Claude Code skills directory to use `/cre-development`.

```powershell
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse .\claude-code-plugins\cre-development "$HOME\.claude\skills\"
```

The plugin includes:

- 8 development and construction skills
- 4 development and construction knowledge bases
- 2 shared CRE references: `underwriting-calc.md` and `risk-scoring.md`

Use it for U.S. ground-up development and heavy redevelopment: site and entitlement screening, budget and yield-on-cost analysis, construction loan sizing, GC contract and change order review, draw and cost-to-complete review, schedule and delivery risk tracking, lease-up and stabilization pro forma, and development IC memo writing.
