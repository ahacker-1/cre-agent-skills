# CRE Capital Markets Plugin

Claude Code plugin for U.S. CRE debt maturity, refinance, workout, recapitalization, and rescue-capital workflows.

## Slash Command

`/cre-capital-markets`

## Included Skills

- Debt Maturity Diagnostic
- Refinance Proceeds Gap Analyzer
- Extension / Workout Strategy Builder
- Rescue Capital Comparator
- Capital Stack Term Sheet Comparator
- CMBS / Special Servicing Readiness Reviewer
- Lender Update Package Builder
- Recap IC Memo Writer

## Included Knowledge Bases

- Capital Markets Benchmarks
- Workout and Extension Structures
- Rescue Capital and Preferred Equity
- CMBS Servicing and Default Playbook
- Underwriting Calculations
- Risk Scoring Framework

## Example Uses

```text
/cre-capital-markets Diagnose the refinance risk for this loan maturing in October.
/cre-capital-markets Calculate the proceeds gap if we refinance this asset today.
/cre-capital-markets Compare these senior debt and preferred equity term sheets.
/cre-capital-markets Build a lender update package for an extension request.
/cre-capital-markets Review CMBS special servicing readiness for this maturity default.
/cre-capital-markets Write the recap IC memo.
```

## Notes

- This plugin is for decision support, not legal, tax, accounting, investment, or financing advice.
- Loan documents, term sheets, PSAs, intercreditor agreements, recognition agreements, and tax consequences require qualified professional review.
- Live lender quotes and executed documents control over static benchmark ranges.
