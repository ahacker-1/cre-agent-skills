# PR Summary: v1.6.0 - Retail, Lender / Credit, and Development and Construction

## What Changed

- Added a Retail v1 pack with 8 new U.S. retail skills, 4 retail knowledge bases, and 12 retail research notes
- Added a Lender / Credit v1 pack with 8 new credit-side skills, 4 lender / credit knowledge bases, and 12 lender / credit research notes
- Added a Development and Construction v1 pack with 8 new development skills, 4 development knowledge bases, and 12 development research notes
- Added the `/cre-retail`, `/cre-lender-credit`, and `/cre-development` Claude Code plugins
- Added `scripts/validate_repo.py`, a cross-platform port of the PowerShell validator, and a second `validate-python` CI job on `ubuntu-latest`
- Updated README, usage docs, skill index, roadmap, changelog, release notes, and GitHub templates for `v1.6.0`
- New repo totals: 90 skills, 35 knowledge bases, 93 research notes, 14 Claude Code plugins

## Why It Matters

- Retail v1 closes the last major core property type in the repo and handles what actually drives retail value: tenant sales, occupancy cost, anchor health, co-tenancy, exclusives, and CAM recovery structure
- Lender / Credit v1 is the first credit-side pack. Every other pack here is borrower, owner, or seller side; this one gives credit analysts, underwriters, portfolio managers, credit officers, loan review, and special assets the same quality of tooling
- Development and Construction v1 covers the interval from site control to stabilization, which no existing pack reached, and hands off cleanly to the stabilized-operations packs
- Cross-platform validation means macOS and Linux contributors can run the same strict gate the Windows validator enforces
- All existing paths, plugin commands, and skill file names are preserved; this release is additive
