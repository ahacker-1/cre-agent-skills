# Extension / Workout Strategy Builder

Build a practical extension, modification, forbearance, or workout strategy for a CRE loan.

---

## When to Use This Skill

Use this skill when a borrower needs more time, cannot refinance at par, is approaching default, or must propose a lender resolution path.

---

## What You'll Need to Provide

- Loan terms, maturity date, lender type, servicing contact, and default status
- Current payoff and collateral value
- Current NOI, rent roll, budget, and business plan
- Extension options and covenant tests
- Sponsor liquidity and proposed contribution
- Desired relief and timing
- Legal or guaranty issues if known

---

## Mission

Translate the borrower's problem into a lender-credible structure that explains the ask, the lender protections, the milestones, and the fallback path.

---

## Strategy

### Step 1: Identify the Real Problem

Classify the request:

- maturity timing problem
- proceeds gap
- temporary cash-flow shortfall
- value impairment
- leasing/capex execution delay
- imminent monetary default
- covenant or reporting default

### Step 2: Select Candidate Structures

Compare:

- short extension
- performance-based extension
- modification
- forbearance
- A/B note split
- discounted payoff
- deed-in-lieu
- sale process standstill

### Step 3: Build the Lender Give/Get

For each requested concession, pair lender protections:

- fee
- paydown
- new equity
- reserve
- cash sweep
- reporting
- milestones
- guarantor support
- consent rights
- deed-in-lieu escrow or release structure, subject to counsel

### Step 4: Prepare Milestones

Create a measurable timeline:

- package delivery
- lender decision
- lease execution
- capex completion
- appraisal/BOV update
- sale launch or refinance launch
- paydown date
- final maturity

### Step 5: Recommend Strategy and Fallback

State:

- primary ask
- minimum acceptable outcome
- fallback if lender refuses
- documents needed before counsel or lender call

---

## Quality Checks

- Matches structure to the actual problem
- Includes lender protections, not just borrower requests
- Identifies default status and servicing path
- Sets measurable milestones
- Flags items requiring legal/tax advice
- Includes fallback path

---

## Red Flags & Dealbreakers

- Borrower asks for extension with no paydown, reserve, or milestone plan
- Property cannot cover taxes, insurance, or life-safety needs
- Guarantor exposure is ignored
- Default interest and fees are not modeled
- Lender consent is assumed for subordinate capital
- Plan preserves ownership but destroys economic value

---

## When Data is Missing

- If loan documents are missing, frame structures as preliminary
- If default status is unclear, identify questions for counsel and lender
- If sponsor liquidity is missing, show alternatives with and without contribution
- If value is missing, require valuation support before recommending discounted payoff or deed-in-lieu

---

## Confidence Scoring

| Level | Criteria |
|---|---|
| HIGH | Loan documents, default status, payoff, financials, value, and sponsor contribution are known |
| MEDIUM | Core facts are known, but legal documents or sponsor liquidity are incomplete |
| LOW | Borrower summary only; no documents or current collateral evidence |
